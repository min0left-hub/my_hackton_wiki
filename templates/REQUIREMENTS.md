# 요구사항

## 프로그램 동작 흐름·진행 현황
갱신 시각:
| 순서 | 사용자 동작 → 프로그램 결과 | 요구 ID·성공 조건 | 구현 상태 | 검증 상태 | 근거/관련 파일 |
|---|---|---|---|---|---|

구현: 미착수/진행 중/구현됨/확인 불가. 검증: 미실행/통과/실패/차단. 실제 근거 없이 완료로 표시하지 않음.

## 승인 상태
상태: 초안 / 검토 요청 / 참가자 승인 (실제 상태 선택)
참가자 승인 내용·시점: 미승인
기획 문서 작성 승인 근거:
구현 승인 근거: 없음 (기획 승인과 구분)
