# 오류 분석과 수정

AGENTS.md의 승인 경계를 따른다. ‘원인만 확인’ 요청에는 편집하지 않는다.

- 기대한 동작, 실제 증상, 실행 위치·명령·오류 메시지를 확인한다.
- 허용된 격리 환경에서 같은 실패를 재현하고 관련 입력·설정·최근 변경을 읽는다.
- 확인된 근거와 가설을 구분해 원인을 좁힌다. 근거 없이 패키지 재설치나 구조 전체 재작성을 반복하지 않는다.
- 승인 범위 내에서 원인과 관련된 부분만 수정한다. 업무 규칙 변경이나 데이터 삭제가 필요하면 해당 조치 전 참가자 확인을 받는다.
- 같은 실패 조건과 영향을 받을 정상 흐름을 실제 재검증한다. 수정 코드가 있다는 이유로 해결됐다고 하지 않는다. 재발 가능성이 있고 자동 검사가 적절한 오류라면 기존에 실패하던 조건을 잡는 회귀 테스트를 추가한다. 단순한 수정 코드 복사본을 정답 기준으로 삼지 않는다.
- 실제 과제가 요구한 문서·경로를 우선해 승인된 기록에 증상·근거·수정 범위·실제 결과·미해결 항목을 남긴다. 기존 결정을 지우지 않고 변경 이유를 추가한다.

시험 자료 반출, 외부 AI, Codex 업데이트, 감독·접속 제한 우회, 금지된 화면 자동 조작을 오류 해결 수단으로 사용하지 않는다.
