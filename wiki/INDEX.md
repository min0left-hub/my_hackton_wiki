# 프로젝트 기억의 입구

상태: 준비 양식. 실제 과제는 아직 시작하지 않았으며, 이 문서는 구현·검증 완료 증거가 아닙니다.

## 새 세션이 읽을 순서
1. ../AGENTS.md의 시작·승인 경계 확인
2. 참가자의 현재 요청과 승인 범위 확인
3. 아래 기록 중 필요한 문서와 현재 실제 파일을 대조

## 작업 기록
아래 경로는 생성 후 링크로 바꾸세요. 현재는 templates에 빈 양식만 있습니다.
- 요구사항: 작성 전
- 결정 기록: 작성 전
- 진행 상태: 작성 전
- AI 협업 기록: 작성 전
- 검증 결과: 작성 전

## 인계 요약
- 참가자 과제 해석: 아직 전달되지 않음
- 승인된 범위: 없음
- 완료한 기능: 없음
- 진행 중/다음 작업: 참가자 해석과 지시 대기
- 실패·미검증: 아직 검사하지 않음
- 실제 실행 명령·포트: 미정
- 작성 시각·작성 세션: 초기 양식

시험 자료가 들어간 완성 기록은 작업 환경 안에만 보관하며 공개 저장소로 올리지 않습니다.
